Pierre/JUZU design mapping

  • File headers are section dividers, closer to Pierre's file-level hierarchy than a plain row.
  • Hunks render as compact blue/purple bands so scan position is obvious without wasting vertical space.
  • Unified gutters now follow Bun DiffView ordering: one active line number, then the +/- sign, then code content.
  • Add/remove/context content spans now fill the remaining row width, matching the Bun `` component's full-row background treatment.
  • Collapse rows are centered separators, not inert text.
From Pierre
file/hunk hierarchy, gutters, collapsed regions, patch reading rhythm.
From JUZU
sharp terminal density, low chrome, high information per line.
