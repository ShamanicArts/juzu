Pierre/JUZU design mapping

  • The structured model still retains file/hunk hierarchy for sidebar previews, hunk jumps, and future virtualization.
  • The full Rust diff pane now filters those scaffold rows and starts with Bun/OpenTUI-style code rows under the file title.
  • Unified gutters follow Bun DiffView ordering: one active line number, then the +/- sign, then code content.
  • Add/remove/context content spans fill the remaining row width, matching the Bun `` component's full-row background treatment.
  • Collapse rows remain available for capped sidebar previews, not the uncapped full pane.
